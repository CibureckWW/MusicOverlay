# MusicOverlay

Плавающий виджет для Windows, который показывает **что играет прямо сейчас** — из Spotify,
Яндекс Музыки, VK/YouTube в браузере, VLC, AIMP, foobar2000 и любого другого плеера,
который виден в системном микшере Windows (SMTC).

![widget](assets/preview.png)

Мини-плеер на панели задач:

![taskbar](assets/preview_taskbar.png)

## Что умеет

- Компактная карточка без рамки, всегда поверх окон, со скруглением и мягкой тенью.
- Обложка альбома, название трека (акцентным цветом), исполнитель и альбом.
- Подпись источника: Spotify / Chrome / Edge / Яндекс Музыка / VLC …
- Кнопки управления на карточке: **предыдущий трек**, **пауза/продолжить**, **следующий трек**.
  Кнопка повтора активна, если плеер отдаёт режим повтора через системный API
  (Chrome, например, его не отдаёт — кнопка будет неактивна).
- Тонкая полоска прогресса воспроизведения. Наведите на неё курсор и кликните
  или проведите по ней, чтобы перемотать трек — прямо из карточки, без браузера.
- Перетаскивание левой кнопкой, позиция запоминается.
- **Режим панели задач:** карточка превращается в компактную полоску с обложкой,
  названием, исполнителем и кнопками управления прямо на панели задач Windows.
  Полоску можно двигать вдоль панели, позиция и монитор запоминаются, а сама она
  мягко возвращается на место, если панель задач переехала или изменилась.
  Как и большая карточка, полоска подчиняется автоскрытию: на паузе или без музыки
  она прячется, а когда трек снова заиграл — возвращается. Прогресс в компактной
  полоске тоже интерактивный: наведите курсор и кликните или проведите по нему,
  чтобы перемотать трек, не открывая браузер.
- Правый клик — меню: пауза/продолжить, перенос на панель задач / возврат на рабочий стол,
  настройки, закрепить, скрыть, выход. Те же действия есть в меню иконки в трее.
- Двойной клик — пауза/продолжить (работает через системный API, то есть в любом плеере).
- Настройки: тёмная / светлая / свой цвет фона, прозрачность, шрифт и размеры,
  закрепление, автоскрытие на паузе, акриловое размытие, ширина карточки,
  режим панели задач.
- Акцентный цвет заголовка подстраивается под обложку трека.
- Появление и сворачивание анимированы: карточка мягко выезжает от ближайшего края
  экрана и растворяется при скрытии.
- Автоскрытие: если музыка на паузе/выключена — виджет плавно сворачивается и возвращается,
  когда трек снова заиграл.
- **Статистика прослушиваний** — отдельная вкладка в настройках: треки и время за сегодня,
  самый популярный исполнитель дня, ТОП-10 треков за неделю и общее время за всё время.
  В историю попадают только треки, игравшие непрерывно дольше 30 секунд.
- Иконка в трее (там же настройки и выход), защита от запуска двух копий.

## Быстрый запуск (готовая сборка)

В репозитории хранится только исходный код — готовый `MusicOverlay.exe` в него не
входит. Соберите его командой `build_exe.bat` (см. раздел ниже) или возьмите готовую
сборку.

1. Откройте папку с проектом.
2. Запустите **`MusicOverlay.exe`** — виджет появится в правом верхнем углу экрана.
3. Включите музыку в Spotify / Яндекс Музыке / вкладке VK или YouTube — карточка
   подхватит трек сама.

Если музыки ещё нет, карточка через пару секунд спрячется (так задумано — она не
должна мешать), а в трее появится уведомление. Иконка в трее всегда рядом: оттуда
можно показать виджет или открыть настройки.

Запустить с автозагрузкой: `Win+R` → `shell:startup` → положить туда ярлык на `MusicOverlay.exe`.

## Запуск из исходников

Требуется Python **3.10–3.12** (пакет `winsdk` не поддерживает 3.13+).

```bat
cd C:\path\to\MusicOverlay
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python MusicOverlay.py
```

Или просто дважды кликнуть `run.bat` (запускает без консольного окна через `pythonw`).

Проверить внешний вид без музыки:

```bat
.venv\Scripts\python MusicOverlay.py --demo
```

Отрисовать превью карточки в PNG (в том числе компактной полоски для панели задач):

```bat
.venv\Scripts\python tools\preview.py
.venv\Scripts\python tools\preview.py --taskbar
```

## Сборка одного exe

```bat
build_exe.bat
```

Результат — `dist\MusicOverlay.exe`, скрипт сразу копирует его в корень папки как
`MusicOverlay.exe` (один файл, Python не нужен).
Сборка использует PyInstaller и `MusicOverlay.spec`.

## Настройки

Правый клик по виджету → **Настройки…** (или иконка в трее).

| Параметр | Что делает |
|---|---|
| Тема | тёмная, светлая, свой цвет фона (палитра или HEX) |
| Акцент | цвет заголовка: авто из обложки или выбранный вручную |
| Прозрачность | 25–100 % (альфа-канал карточки) |
| Режим отображения | перенести плеер на панель задач (компактная полоска) |
| Acrylic | размытие фона «стеклом» (Windows 10/11, экспериментально) |
| Шрифт / размеры | семейство шрифта, размер заголовка и подписи, ширина карточки |
| Закрепить | запрещает случайное перетаскивание; на панели задач пункт меняется на «Открепить от панели задач» |
| Автоскрытие | прятать виджет, когда музыка на паузе или закрыта |
| Прогресс | полоска прослушивания; клик или перетаскивание по ней перематывает трек |
| Источник | подпись приложения, из которого играет музыка |

Переключить режим можно галочкой **«Перенести плеер на панель задач»** в настройках,
пунктом правого клика по карточке или командой в меню иконки в трее. В компактном
режиме полоска перетаскивается вдоль панели задач, а пункт «Закрепить» запрещает
случайный сдвиг. Вернуть большую карточку — тем же пунктом «Вернуть на рабочий стол».

Вкладка **«Статистика»** показывает:

- сколько треков прослушано за сегодня и сколько это заняло времени;
- самого популярного исполнителя за сегодня;
- ТОП-10 треков за последнюю неделю с числом прослушиваний;
- суммарное время за всё время (после 24 часов формат меняется на `дн. / ч. / мин.`).

![stats](assets/preview_stats.png)

Трек считается прослушанным, если играл **непрерывно дольше 30 секунд** — быстрое
перелистывание статистику не портит. История хранится в SQLite-базе
`%APPDATA%\MusicOverlay\music_analytics.db`. Все записи и запросы к ней выполняются
в отдельном потоке, поэтому карточка и анимации не подтормаживают.

Настройки хранятся в `%APPDATA%\MusicOverlay\settings.json`, лог — рядом в
`MusicOverlay.log`.

## Как это работает

Данные берутся из `GlobalSystemMediaTransportControlsSessionManager` (Windows Runtime,
пакет `winsdk`). Это тот же источник, что и мини-плеер в оверлее громкости Windows,
поэтому видны все приложения, публикующие медиа-сессию: Spotify, браузеры
(Chrome/Edge/Firefox и вкладки YouTube/VK/Яндекс Музыки), VLC, AIMP и т. д.

Опрос идёт в отдельном потоке (`QThread` + собственный `asyncio`-цикл) с интервалом
0,8 с; обложка читается из `MediaProperties.thumbnail` и кэшируется по треку.
Аналитика тоже живёт в своём `QThread`: GUI отправляет туда снимки состояния,
а обратно получает уже посчитанные цифры. UI — PySide6, отрисовка карточки
полностью кастомная (`QPainter`), поэтому скругления, тень и прозрачность
выглядят одинаково на Windows 10 и 11.

## Если что-то не работает

- **Виджет пустой, музыка играет.** Проверьте, что в оверлее громкости Windows
  (клавиши `Vol+`/`Vol-`) отображается этот трек. Если нет — плеер не отдаёт метаданные
  системе (например, некоторые версии VK в Firefox).
- **Нет обложки.** Часть приложений (часто браузеры) не публикует thumbnail — виджет
  покажет аккуратную заглушку.
- **Acrylic выглядит странно.** Это недокументированный API; на некоторых сборках
  Windows 11 размытие может подтормаживать. Просто выключите галочку.
- **Кнопка повтора неактивна.** Плеер не сообщает Windows режим повтора (так ведёт себя
  Chrome). Кнопки предыдущего/следующего трека и паузы при этом работают.
- **Не запускается exe.** Посмотрите `%APPDATA%\MusicOverlay\MusicOverlay.log`.

## Структура проекта

```
MusicOverlay/
├─ MusicOverlay.py          точка входа
├─ MusicOverlay.spec        конфиг PyInstaller
├─ run.bat / build_exe.bat  запуск и сборка
├─ requirements.txt
├─ tools/make_icon.py       генерация icon.ico
└─ app/
   ├─ config.py             настройки (JSON в %APPDATA%)
   ├─ analytics.py          SQLite-история и статистика в отдельном потоке
   ├─ media.py              SMTC через winsdk, отдельный поток
   ├─ demo.py               демо-треки для --demo
   ├─ theme.py              палитры и акцент из обложки
   ├─ widgets.py            обложка, текст, прогресс, кнопки, фон карточки
   ├─ overlay.py            окно-оверлей, drag&drop, меню, анимации
   ├─ taskbar.py            поиск панели задач, docking, z-order
   ├─ settings_dialog.py    окно настроек
   ├─ icons.py              иконки кодом
   ├─ win32fx.py            Acrylic + скругление региона
   └─ main.py               контроллер, трей, автоскрытие
```
